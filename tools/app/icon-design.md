# アイコンの考え方

- 「ワンタップ」（太いゴシック）と「収支」（アプリの金額と同じ明朝）を、横幅をぴったりそろえた1つのロゴにする。
- アイコン全体が「タップした瞬間」：真ん中から波紋が広がる（文字の後ろ）。外へ行くほど薄く細く。
- 「プ」の゜はミント色の点にして、タップの跡と波紋の色をそろえる。
- 背景は上が明るく下が深い緑のグラデーション（アプリの「プラス」の緑 #1D6B4A がその間に入る）。
- ロゴは幅の68%。iPhoneの角丸で切られない余白をとる。
- ホーム画面の小ささ（60px 前後）でも「収支」がはっきり、「ワンタップ」も読めることを優先する。

作り方：`python tools/app/make-icon.py` → `powershell -ExecutionPolicy Bypass -File tools\app\make-ios-assets.ps1`
（ほかの案：`--style dot`＝「プ」の゜から波紋、`--style plain`＝波紋なし、`--mincho`＝ワンタップも明朝）
