# 広告を消す（買い切り）設計メモ

2026-10-14 決定。次のアップデート（1.1）に入れる。

## 狙い
- 買い切りの課金「広告を消す」を ¥130 で売る。買った人には、バナーも全画面広告も出さない
- 「購入を復元」も置く（機種変更・入れ直しの人のため。Apple の決まりで必須）
- 画面の並び（1画面に収まる構成）は変えない。Web 版（pachi-shushi.html）の動きも変えない

## 値段
- ¥130、基準の国は **日本**（日本の値段は為替で動かない。海外の値段は Apple が自動で決める）
- App Store Small Business Program（手数料15%）に申し込む前提。手取りは約100円
- 実際の手取りは課金の項目を作る画面で確かめる

## 使う部品
- `@capgo/native-purchases`（8.9.x、Capacitor 8 対応、Apple の StoreKit 2 を直接使う。外部サービスなし）
- 課金の項目の ID：`io.github.maosundev.pachishushi.removeads`（非消耗型）

## 作り
### 新しいファイル `js/purchase.js`（アプリ版だけ。Web 版では読み込まない）
- 起動のたびに Apple に「この Apple ID が今も持っている購入」を問い合わせる
  （`getPurchases({ onlyCurrentEntitlements: true })`。払い戻された購入は出てこないので、そのときは広告を戻す）
- 結果は端末にも覚える（Preferences の `pachi-noads`）。問い合わせに失敗したとき（電波なし）は、覚えている値を使う
- 外に出すもの：`window.Purchase = { owned(): boolean, onChange(fn) }`
- 買う：`purchaseProduct({ productIdentifier })`。成功したら覚えて、`onChange` を呼ぶ
- 復元：`restorePurchases()` のあとにもう一度問い合わせる

### `js/ads.js` の変更
- 読み込みの最初に `Purchase.owned()` を見る。買っていたら、バナーも全画面広告も準備しない。広告枠の高さ `--adh` は 0 にする
- 買った直後（`onChange`）は、その場でバナーを消して（`removeBanner`）、`--adh` を 0 にし、全画面広告を止める
- 追跡許可（ATT）の確認は、広告を出さない人には出さない

### ボタン（`tools/app/build-www.mjs` でアプリ版だけに差し込む）
- 「収支の詳細」画面の CSV の行の下に 1 行足す。見た目は CSV の行と同じ（小さい灰色の下線付きの文字）
  - 買う前：`広告を消す（¥130）・購入を復元`
  - 買ったあと：`広告なし ✓`
- 値段の文字は、Apple から取った値段（`getProduct` の `priceString`）を使う。取れないときは値段を書かない

## 失敗したとき
| 場面 | 動き |
|---|---|
| 買う途中でやめた | 何もしない。広告はそのまま |
| 電波がない・Apple につながらない | 「通信できませんでした。少しあとでもう一度お試しください」 |
| 復元したが見つからない | 「このApple IDでの購入は見つかりませんでした」 |
| 端末の記録が消えた | 次の起動の問い合わせで自動で戻る |
| ボタンを連打した | 処理中はボタンを押せなくする |

メッセージは、アプリにもともとある短い知らせ（`toast`）で出す。

## App Store Connect での準備（ご本人と一緒に）
1. 有料アプリ契約（銀行口座・税金）を有効にする ← 2026-10-14 入力中
2. Small Business Program に申し込む
3. アプリ内課金を作る：種類「非消耗型」、ID は上のもの、表示名「広告を消す」、¥130（基準の国を日本に直す）、審査用のスクリーンショットとメモ
4. 1.1 の審査に出すとき、この課金をバージョンに付けて一緒に提出する

## 確かめ方
- 手元：`npm run build` で www/ にボタンと `js/purchase.js` が入ること。pachi-shushi.html（Web 版）に差分がないこと
- TestFlight：テスト用の購入（お金はかからない）で、ご本人の iPhone で通しで確かめる
  1. 広告が出ている → 「広告を消す」で買う → バナーが消え、広告枠の余白が詰まる
  2. 画像を何回か添付しても全画面広告が出ない
  3. アプリを消して入れ直す → 広告が出る → 「購入を復元」→ 広告が消える
  4. 機内モードで開いても広告が出ない（覚えている値を使う）

## やらないこと
- 外部サービス（RevenueCat など）、サーバーでの購入確認
- 他の課金（寄付・サブスクなど）
- Web 版での課金
